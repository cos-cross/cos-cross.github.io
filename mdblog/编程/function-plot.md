现在这篇文章里的函数图像**是可以交互的** —— 滚轮缩放、拖动平移,3D 的还能拖着转。这篇讲怎么做的,以及为什么最后没有用 plotly 或 three.js。

<!-- more -->

## 先看效果

一条普通的三角函数,拖一下、滚一下都行:

```plot2d x=[-7,7] y=[-2.2,2.2]
sin(x)
```

同一张图里画多条曲线,自动配不同颜色、自动适配 y 范围:

```plot2d x=[-6.5,6.5]
sin(x)/x
cos(x)
```

3D 的曲面麻烦一点,因为要自己算投影、自己排序。**按住拖动可以转**:

```plot3d x=[-5,5] y=[-5,5] grid=54
sin(sqrt(x^2+y^2))
```

这个经典的高斯钟形曲面,换个角度看形状更清楚:

```plot3d x=[-3,3] y=[-3,3] grid=54
exp(-(x^2+y^2)/2)
```

再来个会"打架"的:两个方向的波叠加,转起来看干涉条纹:

```plot3d x=[-6,6] y=[-6,6] grid=64
sin(x)*cos(y)
```

## 为什么不用现成的库

第一反应当然是引库。plotly.js 什么都有,three.js 渲染 3D 也漂亮。但算下来不划算:

| | plotly.js | three.js | 自己写 |
| --- | --- | --- | --- |
| 体积 | 2D 约 1 MB,3D 再加 1.3 MB | 约 600 KB | **约 26 KB** |
| 依赖 | 无,但很大 | 需要自己写曲面 + 控制器 | 无 |
| 国内 CDN | 要能访问,否则得塞进仓库 | 同左 | 不涉及 |
| 能不能验证 | 只能"看起来对" | 同左 | **数学核心可以在 Node 里跑单测** |

最后一条是关键。我没法在这个环境里打开浏览器看效果,引库的话就只能靠运气;而自己写的话,表达式解析、网格生成、投影、深度排序这些都是纯函数,**可以写成单元测试跑一遍**(这份代码有 49 项测试)。

3D 也没用 WebGL,而是 **Canvas 2D + 画家算法**:算出每个四边形四个顶点的屏幕坐标,按深度从远到近排序,依次填充。对 `z = f(x,y)` 这种单值高度场,画家算法几乎不会出错,而且避开了 WebGL 上下文丢失、移动端兼容这些麻烦。代价是网格密度不能太高,默认 46×46。

## 几个实现细节

**1. 数学的 `^` 不是 JS 的 `^`。** 我第一版直接把表达式编译成 JS 字符串,结果 `x^2` 被当成按位异或,`3^2` 算出来是 1 而不是 9。必须显式转成 `Math.pow`。这个 bug 是单测抓出来的 —— 肉眼根本看不出来,因为图还是"有东西"的,只是完全不对。

**2. 旋转矩阵的顺序。** 方位角必须绕"向上"的那根轴转。我第一版把竖直方向混进了水平旋转里,效果是画面在原地打滚。测试里专门验证了:绕竖轴转 90° 后,`x=1` 的点应该跑到 `z=-1`,而高度不变。

**3. 隐式乘法。** `2x`、`3sin(x)`、`(x+1)(x-1)` 都能认。写法上和显式乘法同级,所以 `2x^2 = 2·(x²)` 而不是 `(2x)²`。

**4. 未知符号明确报错。** 打错一个字母时,与其给你一张空图,不如直接说"未知符号: xx"。而且**构建期就会检查一遍** —— 表达式写错了,`npm run build` 的日志里当场报出来,不用等打开网页。

**5. `1/x` 在 0 附近要断开。** 非有限值处直接断开路径,否则会连出一条竖直的假线。

## 怎么用

在文章里写一个带 `plot2d` / `plot3d` 标记的代码块就行:

````markdown
```plot2d x=[-7,7] y=[-2,2]
sin(x)
cos(x)
```
````

表达式一行一个,`#` 开头的行会被忽略(可以当注释)。

**可用选项:**

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `x=[a,b]` | 2D `[-10,10]` / 3D `[-5,5]` | 横轴范围 |
| `y=[a,b]` | 2D 自动适配 / 3D `[-5,5]` | 纵轴范围(3D 时是第二个自变量) |
| `z=[a,b]` | 自动 | 3D 颜色映射的高度范围 |
| `grid=n` | 46 | 3D 网格密度,最高 90 |
| `n=n` | 900 | 2D 采样点数 |

**支持的函数:** `sin` `cos` `tan` `asin` `acos` `atan` `sinh` `cosh` `tanh` `exp` `log` `ln` `log2` `log10` `sqrt` `cbrt` `abs` `sign` `floor` `ceil` `round` `min` `max` `pow` `hypot` `mod` `clamp`,以及两个我自己加的 `sinc(x)` 和 `gauss(x, σ)`。常量有 `pi` `e` `tau`。

## 还支持隐式方程

前面画的都是 `y = f(x)` 这种"显式"函数。但圆锥曲线、球面这类东西写成 `f(x,y)=0` 要自然得多,所以也支持了。

**只要式子里有等号,就按隐式方程处理。** 圆锥曲线三兄弟:

```plot2d x=[-3,3]
x^2 + y^2 = 1
x^2/4 + y^2 = 2
x^2/2 - y^2 = 1
```

注意画布会自动变成**正方形**,而且纵轴默认取和横轴一样宽 —— 不然圆会被压成椭圆。这一条很容易被忽略:隐式曲线必须横纵等比例才是它本来的形状。

球面,拖一下就能看清是个球:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=34
x^2 + y^2 + z^2 = 1
```

环面 —— 四次方程,`(x²+y²+z²+R²)² = 4R²(x²+y²)`:

```plot3d x=[-2.4,2.4] y=[-2.4,2.4] z=[-2.4,2.4] grid=36
(x^2 + y^2 + z^2 + 0.6)^2 = 4*(x^2 + y^2)
```

显式和隐式还能混在同一张图里:

```plot2d x=[-4,4] y=[-4,4]
x^2 + y^2 = 4
sin(x)
```

一张图里还能叠**多个**曲面/等值面。下面这个是正四面体四个顶点上各放一个球,两两相切(球心间距正好是 `2r`):

```plot3d x=[-4,4] y=[-4,4] z=[-4,4] grid=34
point(0, 0, sqrt(2)) A
point(1, 0, 0) B
point(-1/2, sqrt(3)/2, 0) C
point(-1/2, -sqrt(3)/2, 0) D
(x-1)^2+y^2+z^2=3/4
(x+1/2)^2+(y-sqrt(3)/2)^2+z^2=3/4
(x+1/2)^2+(y+sqrt(3)/2)^2+z^2=3/4
x^2+y^2+(z-sqrt(2))^2=3/4
```

多曲面时**按曲面轮流换色**(而不是按高度渐变),一眼能看出哪块是哪个式子。

### 半透明

四个球叠在一起,如果全是不透明的,前面的球会把后面的挡掉大半。所以**多个曲面默认就是半透明的**,工具条上那个「半透明」按钮可以来回切。

也可以自己指定透明度(0.05 ~ 1):

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=32 alpha=0.35
x^2 + y^2 + z^2 = 1
x^2 + y^2 + z^2 = 3
```

`alpha=` 越小越透。单个曲面默认不透明(实心的球好看),想要玻璃球写 `alpha=0.5` 就行。

半透明不是"整张图统一压一个 alpha"那么简单 —— 那样只能看到球正面那一层,背面被同色的正面盖住,反而没有透明的感觉。这里的做法是**每个四边形各自带 alpha、按深度从远到近画**,所以近处的面会真的和远处的面叠在一起。

代价是不能再靠"同色描边"去压相邻面之间的缝了(每条棱都会再叠一层 alpha,整张网格线会浮出来),所以半透明时改成把每个面从重心往外撑开 0.6 像素,让相邻面互相咬住。另外半透明时着色也会少压暗一点,不然深色背景下几乎看不见。

### 线段和多边形面

除了曲面,也能直接画空间里的**线段**和**平面多边形** —— 立体几何作图基本就靠这两个。

顶点直接复用在 `point(...)` 里定好的标签:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] alpha=0.4
point(1, 1, 1) A
point(1, -1, -1) B
point(-1, 1, -1) C
point(-1, -1, 1) D
polygon(A, B, C)
polygon(A, B, D)
polygon(A, C, D)
polygon(B, C, D)
segment(A, B)
segment(A, C)
segment(A, D)
segment(B, C)
segment(B, D)
segment(C, D)
```

这就是正四面体。四个面各自一个颜色、按平面法线打光,棱线用线段描在最上层。

懒得先定义点也行,坐标直接写在括号里(`(x, y, z)`,2D 写两个):

```plot3d x=[-2,2] y=[-2,2] z=[-2,2]
segment((0, 0, 0), (1, 1, 1))
segment((0, 0, 0), (-1, 1, 0))
polygon((1, 1, 1), (-1, 1, 0), (0, 0, 0))
```

规则很简单:**不带括号就是点的标签,带括号就是坐标**。所以 `segment(A, B)` 是连线,`segment((1,2), (3,4))` 是现写坐标;光写 `segment(1, 2)` 会直接报错(分不清那到底是标签还是数字)。

线段支持 `where`,而且是**按小段裁**的:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2]
x^2 + y^2 + z^2 = 1
z > 0
segment((0, 0, -1.5), (0, 0, 1.5)) where z > 0
```

整条线会被切成十几小段分别排序,所以一条从球前面穿到球后面的棱,遮挡关系是逐段正确的(不会整根被挡住、也不会整根盖在球上);`where` 也是逐段判定的,所以上面那条轴只剩上半截。

2D 一样能用,做平面几何的图挺方便:

```plot2d x=[-1,4] y=[-1,4]
point(0, 0) O
point(3, 0) A
point(0, 3) B
point(1.5, 1.5) M
polygon(O, A, B)
segment(A, B)
segment(O, M)
```

### 两种方程背后是两套完全不同的算法

| | 显式 | 隐式 |
| --- | --- | --- |
| 2D | 逐点采样,连成折线 | **marching squares**:在每个小格上看四角正负号,在符号变化的边上插值出交点再连起来 |
| 3D | 生成高度场网格 | **surface nets**:每个"有符号变化"的立方体格子里放一个顶点,再对每条有符号变化的网格棱拼一个四边形 |

3D 隐式这块本来该用经典的 **marching cubes**,但它需要一张 256 项、每项最多 16 个索引的查找表 —— 手抄这种东西错一个数字就会在某些角度冒出一块诡异的面。**surface nets** 不需要任何查找表,代码短得多,而且产出的正好是四边形,能直接喂给现有的画家算法渲染器。

两个算法都有个容易翻车的点:

- **marching squares 的鞍点**。一个格子里出现 4 个交点时(比如 `f = x·y` 在原点附近),必须看**格子中心**的正负号才能决定该"上下连"还是"左右连"。省掉这一步,双曲线在某些位置会出现莫名其妙的交叉连线。
- **surface nets 的边界**。曲面如果正好贴到包围盒的面上,那一圈会缺几个面片。把范围开大一点就好。

### 选项上的区别

隐式 3D 需要三个轴的范围,所以 `z=` 在隐式下表示**第三个坐标轴**,而显式下表示颜色映射的高度范围:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=34
x^2 + y^2 + z^2 = 1
```

`grid` 对隐式 3D 建议不要开太高(默认 32):曲面网格的四边形数量是显式高度场的好几倍,开太高拖动会掉帧。

## 约束条件:把图形裁成你想要的那一块

**只要一行里出现 `<` `>` `<=` `>=`,它就自动被当成约束条件** —— 约束会裁掉其他所有图形(曲线、方程、曲面)落在区域外的部分。不需要什么新语法。

上半球,一行搞定:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=34
x^2 + y^2 + z^2 = 1
z > 0
```

约束是组合的,写几行就叠几层。下面这个球被两个半空间同时切:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=32
x^2 + y^2 + z^2 = 1
z > 0
x + y < 0
```

2D 也一样。单位圆上 `x < y` 的那段弧:

```plot2d x=[-2,2]
x^2 + y^2 = 1
x < y
```

### 只写约束条件 = 画区域

如果一个 2D 代码块里**只有约束条件**,那就画满足条件的区域(填充 + 描边):

```plot2d x=[-2,2]
x^2 + y^2 < 1
```

几个区域叠起来就是交集 —— 比如"单位圆内且第一象限":

```plot2d x=[-2,2]
x^2 + y^2 < 1
x > 0
y > 0
```

### 约束是怎么实现的

| 图形 | 裁剪方式 |
| --- | --- |
| 显式 2D 曲线 | 采样时逐点判定,不满足就**断开折线** |
| 隐式 2D 等值线 | 线段两端都必须满足约束才保留 |
| 3D 高度场 | 网格点标成空值,引用它的四边形自动消失 |
| 3D 等值面 | 顶点在约束外就不生成,四边形自然消失 |
| 区域 | 逐个格子判定中心是否满足,满足的格子并成一个路径一次填充 |

区域填充有个小细节:所有格子必须**塞进同一条路径再 fill**。如果一格一格地 fill,格子相邻处会因为两次半透明叠加而出现明显的网格接缝。

内部实现上,四种比较符号统一归一化成 `g > 0` / `g >= 0`(`a < b` 就变成 `b - a > 0`),判定逻辑只剩一个符号问题。

> 注意比较符号的识别顺序:`<=` / `>=` 必须排在 `<` / `>` 前面 —— 否则 `x <= y` 会被当成 `<` 后面跟了个 `=`。

## 单独的点

用 `point(x, y)` 或 `point(x, y, z)`,后面可以跟一个标签:

```plot2d x=[-4,4] y=[-1.6,1.6]
y = sin(x)
point(0, 0) O
point(pi/2, 1) A
point(pi, 0) B
```

坐标是**常量表达式**,所以 `pi/2`、`sqrt(2)` 都能直接写。点也会被约束条件管 —— 在约束外的点不会画出来:

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=30
x^2 + y^2 + z^2 = 1
z >= 0
point(1, 0, 0) X
point(0, 1, 0) Y
point(0, 0, 1) Z
point(0, 0, -1) 看不见
```

**边界上写 `>` 还是 `>=` 会差很多。** 上面如果写成 `z > 0`,虽然球面看起来差不多,但**赤道上的 X 和 Y(它们的 z 正好是 0)会被一起排除掉**,四个点只剩一个。曲面本身和约束的边界相交时,严格的 `>` 会把整条交线切掉,`>=` 才会留下。

**3D 的点会和曲面一起按深度排序**,所以球背面的点会被球正确地挡住,而不是浮在最上面。半径也随透视缩放,靠近时自然变大。

### 给每条曲线单独定制约束

上面那种独立成行的约束是**全局**的,会把这张图里所有东西一起裁。但很多时候你想要的恰恰相反 —— 比如"这条只画右半边,那条只画左半边"。

用 `where` 跟在这一行后面就行:

```plot2d x=[-7,7] y=[-1.6,1.6]
y = sin(x) where x >= 0
y = cos(x) where x < 0
```

多个条件用 `and` 连接(`&&` 也可以):

```plot2d x=[-7,7] y=[-1.6,1.6]
y = sin(x) where x > -4 and y > 0
y = cos(x) where x > 2
```

隐式方程、3D 曲面同样支持:

```plot2d x=[-2,2]
x^2 + y^2 = 1
y = x where x^2 + y^2 > 1
```

```plot3d x=[-2,2] y=[-2,2] z=[-2,2] grid=34
x^2 + y^2 + z^2 = 1 where z > 0
```

### 全局和局部是**叠加**的,不是覆盖

不带 `where` 的独立约束行仍然全局生效,它会被并进每一条的约束里:

```plot2d x=[-4,4] y=[-2,2]
x >= -2
y = sin(x) where y > 0
y = cos(x)
```

上面这张图的实际效果是:

| 曲线 | 实际生效的约束 |
| --- | --- |
| `sin(x)` | `x >= -2` **且** `y > 0` |
| `cos(x)` | `x >= -2` |

也就是**先按整张图的限制裁一遍,再按各自的 `where` 裁一遍**。这个语义比"有 where 就无视全局"更可预测 —— 全局约束的意思是"这张图整体只看这一块",不该被某一条曲线悄悄绕过。

### 每个点也可以有自己的约束

`where` 对点同样有效,而且标签和 `where` 可以同时写:

```plot2d x=[-3,3] y=[-3,3]
x^2 + y^2 = 4
point(2, 0) 在圆上 where x > 0
point(-2, 0) 这个看不到 where x > 0
```

第二个点虽然画在 `x = -2` 的圆上,但被自己的 `where x > 0` 排除了,不会出现。

## 交互

- **2D**:滚轮缩放(以鼠标位置为锚点)、拖动平移、双击重置
- **3D**:拖动旋转、滚轮缩放、双击重置
- **触屏**:单指拖动、双指捏合缩放
- 右上角有「重置」和「存为 PNG」—— 写作业要用图的话直接存下来
- **3D** 还有「半透明」开关:球套球、多个曲面互相遮挡的时候按一下就能看穿

绘制代码只在**含图像的页面**加载,其他页面完全不受影响。
