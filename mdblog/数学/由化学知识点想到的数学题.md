但第三个问题却是第二个问题在极值时构造, 看上去难度肯定比前两个要简单不少

考虑一个局部的四个球(令球心为$r$):

```plot3d x=[-2.4,2.4],y=[-2.4,2.4],z=[-2.4,2.4] grid=48
point(0, 0, sqrt(2)) A
point(1, 0, 0) B
point(-1/2, sqrt(3)/2, 0) C
point(-1/2, -sqrt(3)/2, 0) D
(x-1)^2+y^2+z^2=3/4
(x+1/2)^2+(y-sqrt(3)/2)^2+z^2=3/4
(x+1/2)^2+(y+sqrt(3)/2)^2+z^2=3/4
x^2+y^2+(z-sqrt(2))^2=3/4
segment(A,B)
segment(A,C)
segment(A,D)
segment(B,C)
segment(B,D)
segment(C,D)
```

由球心形成正四面体$ABCD$, 想要求空间利用率, 就是算四个球和与正四面体重合体积与正四面体体积之比

而正四面体体积我们是知道的: $V = \cfrac{2\sqrt{2}}{3}r^2$

重合部分在四个球心上应该是对称相同的, 我们只需要求一个球心上的对称部分就可以了

为此, 我们只需求下面一个几何体的体积:

```plot3d x=[-1.05,1.05],y=[-1.05,1.05],z=[-1.05,1.05] grid=48
point(0, 0, 0) O
point(1, 0, 0) A
point(1/2, sqrt(3)/2, 0) B
point(1/2, sqrt(3)/6, sqrt(6)/3) C
polygon(O, A, B)
polygon(O, B, C)
polygon(O, C, A)
x^2+y^2+z^2=1 where y > -sqrt(3)*(x-1)/3 and x > 1/2 and z < sqrt(6)/3 and z > 0
```
