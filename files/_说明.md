# files/ —— 要分享给别人的文件放这里(小文件)

这个文件夹里的**所有文件**会在 `npm run deploy` 时:

1. 复制到 `source/files/`,发布到 **`/files/<相对路径>`**;
2. 自动在 **`/files/`** 页面按子目录分组列出来(带大小、日期、sha256 前 8 位);
3. 页面顶部有输入框,可以按文件名筛选。

**超过 100 MB 的大文件不要放这里 —— 放仓库根目录的 `files-big/`。**
git 仓库单文件上限就是 100 MB,超了整次 push 会被 GitHub 拒绝(部署直接挂);
`files-big/` 里的文件不进仓库,而是传到 GitHub Release(单个上限 2 GB,不占仓库体积),
页面上的链接会自动变成 Release 直链,并标一个 `Release` 角标。

```bash
npm run files                # 只同步,不构建不发布
npm run files -- --dry-run   # 只看会做什么,不落盘
npm run files:release        # 把 files-big/ 里的传到 GitHub Release(需要 GITHUB_TOKEN)
npm run deploy               # 同步 + 构建 + 发布
```

`npm run build` / `npm run check` / `npm run deploy` 都会自动先跑一次。

## 例子

```text
files/                                  →  本站直链
├── 数学/
│   ├── 三角函数公式速查.pdf             →  /files/数学/三角函数公式速查.pdf
│   └── 数列练习题答案.docx              →  /files/数学/数列练习题答案.docx
├── 代码/
│   └── oi-template.zip                 →  /files/代码/oi-template.zip
└── 说明.txt                            →  /files/说明.txt

files-big/                              →  GitHub Release 直链(本体不进仓库)
└── 游戏/
    └── DELTARUNE.zip                   →  https://github.com/<你>/<仓库>/releases/download/files/DELTARUNE.zip
```

子目录名就是下载页上的分组名。文件名里的中文、空格都会自动做 URL 编码,不用管。

## 几条硬限制

**`files/` 是"把文件提交进 git 仓库"的方案,不是对象存储;`files-big/` 走 Release。**

| 限制 | 数值 |
| --- | --- |
| git 仓库单文件上限 | **100 MB**(超了整次 push 被拒,不是跳过那一个文件) |
| Release 单个资源上限 | **2 GB** |
| Pages 发布站点 | 不得超过 **1 GB** |
| 仓库建议体积 | 1 GB 以内 |
| 体积放大 | `files/` 里的文件在 `main` 和 `gh-pages` 各存一份,**占用约等于体积 ×2** |

所以:

- ✅ PDF、课件、代码包、图片、字体 —— 放 `files/`,没问题
- ⚠️ 单个超过 20 MB,同步时会给提示
- ❌ 视频、游戏包、系统镜像 —— 放 `files-big/` 走 Release;再大(> 2 GB)就得用真正的对象存储
  (Cloudflare R2 / 阿里云盘 / Alist 等,见 README)

## 规则

- **`_` 和 `.` 开头的文件/文件夹会被跳过**,用来放说明、临时文件。
- **删掉即下线。** 从这里删掉一个文件,`source/files/` 和 `public/files/` 里的副本都会在下次同步时清掉
  (Hexo 自己不清理 `public/`,这一步由同步脚本负责 —— 否则老文件会被一直推到 gh-pages 上)。
- `= index.md` 是下载页本身的模板,不能被文件覆盖(重名会被跳过并提示)。
- 想验证下载是否完整,对比页面上的 `sha:` 值和
  `certutil -hashfile <文件> SHA256`(Windows)/ `shasum -a 256 <文件>`(macOS / Linux)的输出前 8 位。
