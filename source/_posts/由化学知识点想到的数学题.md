## 问题转化

将问题抽象化一下, 每个金属原子都是一个半径为r的球, 原子核都是球心

考虑密堆积时局部的相邻四个球(令球心为$r$):

```plot3d x=[-2.4,2.4],y=[-2.4,2.4],z=[-2.4,2.4] grid=48
point(0, 0, sqrt(2)) A
point(1, 0, 0) B
point(-1/2, sqrt(3)/2, 0) C
point(-1/2, -sqrt(3)/2, 0) D
(x-1)^2+y^2+z^2=3/4
(x+1/2)^2+(y-sqrt(3)/2)^2+z^2=3/4
(x+1/2)^2+(y+sqrt(3)/2)^2+z^2=3/4
x^2+y^2+(z-sqrt(2))^2=3/4
segment(A,B)
segment(A,C)
segment(A,D)
segment(B,C)
segment(B,D)
segment(C,D)
```

由球心形成正四面体$ABCD$, 想要求空间利用率, 就是算四个球和与正四面体重合体积与正四面体体积之比

而正四面体体积我们是知道的: $V = \cfrac{2\sqrt{2}}{3}r^2$

重合部分在四个球心上应该是对称相同的, 我们只需要求一个球心上的对称部分就可以了

为此, 我们只需求下面一个几何体的体积:

```plot3d x=[-1.05,1.05],y=[-1.05,1.05],z=[-1.05,1.05] grid=48
point(0, 0, 0) O
point(1, 0, 0) A
point(1/2, sqrt(3)/2, 0) B
point(1/2, sqrt(3)/6, sqrt(6)/3) C
polygon(O, A, B)
polygon(O, B, C)
polygon(O, C, A)
x^2+y^2+z^2=1
```

只需算一下这样一个以球底锥体得体积

原本主包以为直接算这个东西会很容易, 毕竟半径知道, 想求体积只需要求**球面三角形面积**, 想求面积只需要**立体角**,这么个简单几何体立体角一定是"**好算的**"

However, 主包剥蒜但是发现卡住了
